# Docklight brand direction

## Name

**Docklight** is the chosen product name. It works in English without a mythology reference and joins two useful ideas: a dock for containers and a light that makes their state easy to read.

Two alternate names worth keeping for future naming checks are **Relay** (short, international, suggests dependable operation) and **Launchdeck** (more explicit about deployment, with a more playful tone). Docklight is the current product identity and the implementation uses it throughout the interface.

## Mark and visual system

The symbol is a compact geometric loading bay with one illuminated aqua panel. It stays legible at small sizes as a flat SVG and avoids mascots, regional symbols, and game-specific imagery. The wordmark uses a neutral sans serif.

- Graphite backgrounds keep status colors readable in a control panel.
- Aqua marks active navigation and primary actions.
- Warm amber is reserved for warnings and attention states.
- Light and dark themes use the same shape and semantic colors.

The browser UI uses this mark from `web/brand.svg`. The old internal project, binary, service, and API names remain for compatibility until a migration is planned.
