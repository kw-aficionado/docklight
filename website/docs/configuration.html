Configuration reference

The installer creates /etc/yggdrasil/config.yaml. yggdrasil gen-config [PATH] creates the same block-style YAML format and refuses to overwrite an existing file. The installer sets the file to root:yggdrasil mode 0640; the daemon needs read access, not write access during normal operation.

The config reader supports scalar block-style YAML for these keys. Unknown keys fail startup with a line number. Quotes around scalar values are accepted; nested objects and general YAML features are not supported.

KeyDefaultMeaning
server.host0.0.0.0Listener interface. Set to a trusted host address to avoid listening on every interface.
server.port8080HTTP listener port, from 1 through 65535.
server.public_urlemptyCanonical panel origin used in password-reset emails, for example https://panel.example.com. HTTPS is required except for localhost loopback. When empty, Docklight uses the request origin; set this when a reverse proxy or public hostname is involved.
database.path/var/lib/yggdrasil/yggdrasil.dbSQLite database path. Server directories are stored beside the database in servers/.
auth.secret_keygeneratedAt least 32 characters. Used for signed sessions and AES-GCM secret encryption. Keep it stable and back it up with the database.
auth.session_ttl_hours168Session lifetime in hours; must be at least 1.
admin.usernameadminUsername created when the database has no enabled administrator.
admin.passwordgenerated on first configOne-time bootstrap password. It is removed from the config after the administrator is created.
docker.socketunix:///var/run/docker.sockDocker Engine Unix socket. The daemon account must have permission to use it.
docker.api_versionv1.45Versioned Docker Engine HTTP API prefix.
docker.rclone_imagerclone/rclone:1.75.2Pinned helper image used for rclone cloud-drive backup targets.
docker.pbs_client_imageghcr.io/docklight/pbs-client:4.2.8Linux/amd64 helper image containing the Proxmox Backup Client. Build and publish the image from deploy/pbs-client/ or point this setting at your own compatible image.
backups.path<database directory>/backupsLocal encrypted backup directory. Relative paths resolve against the database directory. Keep it outside servers/.
backups.retention10Number of recent local and remote backups retained per server; from 1 through 100.
ports.range_min25000First host port eligible for allocation; minimum is 1024.
ports.range_max30000Exclusive upper bound for allocated host ports; maximum is 65535.

server.demo_mode is accepted but ignored for compatibility with early generated configs. It is not written by the current generator.

Example

server:
  host: 192.168.1.20
  port: 8080
  public_url: https://panel.example.com
database:
  path: /var/lib/yggdrasil/yggdrasil.db
auth:
  secret_key: replace-with-a-generated-secret-at-least-32-characters
  session_ttl_hours: 168
admin:
  username: admin
docker:
  socket: unix:///var/run/docker.sock
  api_version: v1.45
  rclone_image: rclone/rclone:1.75.2
  pbs_client_image: ghcr.io/docklight/pbs-client:4.2.8
backups:
  path: /var/lib/yggdrasil/backups
  retention: 10
ports:
  range_min: 25000
  range_max: 30000

Do not change auth.secret_key after servers or TOTP have been configured: encrypted secrets will no longer decrypt and existing sessions will stop validating. To rotate it safely, a future migration/rotation command is required; it is not available in this release.

Local backup files use the same key. Keep auth.secret_key with the SQLite database and backup directory so a restored installation can decrypt them.
